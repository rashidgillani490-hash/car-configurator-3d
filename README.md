An interactive, photorealistic 3D automotive studio and bespoke configurator for the **BMW M5 (F90 LCI / CS)** built with **React**, **Three.js (`@react-three/fiber` & `@react-three/drei`)**, **Tailwind CSS**, and **Vite**.

🌐 **Live Production Link**: [https://car-configurator-3d-roan.vercel.app](https://car-configurator-3d-roan.vercel.app)

---

## Features

### 1. High-Poly 3D BMW M5 F90 LCI / CS Model
- **3 Curated Factory Editions**:
  - **M5 F90 LCI STEALTH**: Murdered-out Black Sapphire Metallic with Jet Black Style 789M Forged Wheels, M Compound Red Calipers, and Shadowline Black Kidney Grille.
  - **M5 CS (F90)**: Frozen Deep Green Metallic Matte with M5 CS Gold Bronze 789M Wheels, Yellow LCI Laser DRLs, and Carbon-Ceramic Gold Calipers (`627 HP`, `0–60 in 2.6s`).
  - **M5 COMPETITION**: Marina Bay Blue Metallic with Bi-Color Diamond-Cut 789M Wheels and Ice White Laser DRLs.
- **Interactive Mechanical Assemblies**:
  - **Front Saloon Doors**: Open and close front doors on authentic hinges to inspect the M interior cabin.
  - **S63 V8 Power-Dome Hood**: Lifts open the sculpted aluminum hood to reveal the 4.4L S63 M TwinPower Turbo V8 engine bay.
  - **F90 LCI Dual "L-Blade" Laser DRLs**: Signature twin L-blade daytime running lights with switchable CS Yellow / Ice White projector beams.
  - **M xDrive Rolling Road Mode**: Spins all 4 wheels and cross-drilled brake rotors while keeping the 6-piston M brake calipers stationary, accompanied by wind-tunnel aerodynamic airflow streamlines.

### 2. BMW Individual Customizer
- **10 BMW Individual Paints**: Black Sapphire Metallic, Frozen Deep Green, Marina Bay Blue, Brands Hatch Grey, Aventurine Red III, Alpine White III, Isle of Man Green, Sao Paulo Yellow, Brooklyn Grey, and Twilight Purple + Custom Hex PTS Picker.
- **4 PBR Surface Finishes**: Metallic Clearcoat, BMW Individual Frozen Matte, Individual Ceramic Pearl, and Full M Carbon Body Conversion.
- **4 M Forged 789M / 810M Styling Modes**: Monoblock, Bi-Color Diamond-Cut, M5 CS Track Spec, and Dark Tint.
- **5 Rim Alloy Finishes & 5 M Brake Caliper Finishes**.
- **4 3D Showroom Environments**: M Studio Dark Showroom, Stealth Detail Bay, Munich Night Garage, and Autobahn Wind Tunnel.

## Local Development

```bash
# Clone the repository
git clone https://github.com/rashidgillani490-hash/car-configurator-3d.git

# Navigate into the project
cd car-configurator-3d

# Install dependencies
npm install

# Start development server
npm run dev
```
