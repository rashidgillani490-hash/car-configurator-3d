# AETHER // 3D Supercar Studio & Interactive Configurator

An interactive 3D automotive showroom and bespoke car configurator built with **React**, **Three.js (`@react-three/fiber` & `@react-three/drei`)**, **Tailwind CSS**, and **Vite**.

## Features

- **3 Sculpted Supercar Archetypes**:
  - **AETHER V12 VALKYRIE**: Mid-engine aerodynamic hypercar (`1,180 HP`, roof snorkel scoop, dorsal shark fin, dual-plane DRS rear wing).
  - **KRONOS GT-R SPECTRE**: Widebody track grand tourer (`860 HP`, swan-neck GT wing).
  - **SOLARIS EV-X CONCEPT**: Quad-motor cyber prototype (`1,420 HP`, full-width front laser lightbar, active aero blade).
- **Real-Time PBR Paint & Material Finish Customizer**:
  - **10 Factory Automotive Paints** + **Paint-to-Sample Custom Hex Picker**.
  - **4 PBR Surface Shaders**:
    - *Liquid Metallic* (Mirror clearcoat + high metallic flake)
    - *Stealth Satin Matte* (Low-sheen diffused military satin)
    - *Iridescent Pearl* (High-specular multi-layer ceramic coat)
    - *Exposed Forged Carbon* (Real-time procedural 2x2 twill carbon fiber weave texture & bump map)
- **4 Custom 3D Forged Rim Geometries & Brake Customizer**:
  - *10-Spoke Forged Mag*, *Aero Turbofan Disc*, *5-Twin Deep Concave*, and *Hex-Matrix Carbon Rim*.
  - **5 Rim Alloy Finishes** (Brushed Champagne Gold, Satin Gunmetal, Diamond-Cut Silver, Gloss Obsidian, Motorsport Bronze).
  - **5 6-Piston Carbon-Ceramic Brake Caliper Colors** + cross-drilled brake rotors.
- **Carbon Aero Trim & Canopy Glass Tints**:
  - Customize the front splitter, canards, side skirts, rear venturi diffuser, and active rear wing in *Gloss Carbon Fiber*, *Brushed Titanium*, *Stealth Anodized Black*, or *24K Gold Track Accent*.
- **Interactive Vehicle Animations & Studio Environments**:
  - **Animated Dihedral Scissor Doors**: Open/close doors to inspect the carbon bucket seats, racing yoke steering wheel, and glowing telemetry HUD.
  - **Active DRS Aero Wing**: Deploy or stow the hydraulic rear wing.
  - **Wind Tunnel / Rolling Road Mode**: Spins the wheels and rotors, activates aerodynamic downforce streamlines over the bodywork, and scrolls the wind-tunnel light arches.
  - **4 Studio Environments**: *Obsidian Showroom*, *Neon Cyber Garage*, *Apex Wind Tunnel*, and *Solaris Warm Gallery*.
  - **6 Smooth Camera Presets & 3D Engineering Hotspots**.
  - **Photo Mode & High-Res PNG Render Capture**.

## Quick Start

```bash
npm install
npm run dev
```
